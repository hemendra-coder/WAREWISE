# UI/UX Pro Max Guidelines (nextlevelbuilder/ui-ux-pro-max-skill)

This application is built with the **UI/UX Pro Max** design intelligence system.

## Key Design Principles
- **Archetype**: Editorial & Architectural Minimalist Logistics OS.
- **Palette**: Warm Linen (`#F8F7F4`), Deep Ink (`#1C1917`), Terracotta (`#E27B58`), Warm Separators (`#E7E5E0`).
- **Typography Pairing**:
  - Display: `Cormorant Garamond` (600 italic)
  - Monospace / Metadata: `Space Mono` (letter-spacing 0.1em)
  - UI Body: `Inter` (regular / medium / semibold)
- **Geometry & Hierarchy**:
  - Nested radius rule: Inner Radius = Outer Radius - Container Padding
  - Strict 8pt grid, 2x button padding ratio, WCAG AA 4.5:1+ contrast.
- **Craftsmanship**: Clean borders, purposeful telemetry badges, motion-driven feedback, zero AI visual cliches.
